# 积分方程求解基准（S1）

方程形态：`∫_{a(x)}^{b(x)} F(t, x) dt = c`，对参数 x 求解。运行：`node tools\inteq-solver.test.js`，结果 `pass 28 / 28`。
默认参数：Simpson 子区间 n=128，扫描步数 steps=2000，Brent tol=1e-12。

## 容差依据

- Brent 停止判据为区间半宽 ≤ 2ε|x| + tol/2（ε=2.22e-16），根误差上界取 B(x)=2(2ε|x|+tol/2)≈1e-12。
- 例 1-5 被积函数对 t 的次数 ≤1，Simpson 精确，剩余误差只有求和舍入 n·ε·|I|，经 1/|G'(x*)| 传到根上。容差 = 10×(B(x) + n·ε·|I|/|G'|)，10 倍为安全系数。
- 例 7 被积函数 cos t，Simpson 截断误差 ≤ x·h⁴/180·max|cos|（h=x/n），经 1/|G'|=1/|cos x| 传到根上。容差 = 10×(B(x) + x·h⁴/180/|cos x|)。

## 收敛检验（例 8）

- 8a，例 5 取 n=32/64/128：误差均为 5.62e-14，不随 n 变化。原因是被积函数 t+x 对 t 线性，Simpson 在任何 n 下都精确，误差已在舍入层面，单调下降无法观测。断言改为三者都在各自 n 的舍入容差内，已通过。
- 8b，为验证单调下降，补充同形态（限与被积函数都含 x）的非多项式例 `∫_0^x (e^t + x) dt = 4`，即 e^x − 1 + x² = 4，参考根由二分法求得 x*=1.2411…：

## 错误输入例（均返回 ok:false 与中文 error，不抛异常）

xMin>=xMax、c 非数、F 不是函数、F 恒返回 NaN、F 抛异常、lower 不是函数、xMin 为 NaN、steps 为负、未传参数对象。另测 `integrate(null,…)` 返回 NaN，`integrate(t³, 0, 2, 0, 7)` 把奇数 n 自动取偶后结果为 4。
